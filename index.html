帮我写一个快速排序
好的，下面是 Python 实现：
def quicksort(a):
    if len(a) <= 1:
        return a
    p = a[len(a) // 2]
    return quicksort([x for x in a if x < p]) + [p] + quicksort([x for x in a if x > p])

数据备份与迁移

把全部对话、已归档、系统提示词、模型与 API Key 导出为一个 JSON 文件；换电脑或重装后，一键导入即可完整恢复。

应用每小时自动在本地保存一份对话备份（不含 API Key，滚动保留最近 8 份），以防意外丢失。

⚠️ 导出文件包含你的 API Key，请妥善保管、不要随意分享。导入会覆盖当前的全部对话与设置。

一个简洁、快速的桌面 AI 对话工具，专注顺手的多轮对话与隐私自主。

  • 速答浮条全局快捷键随处唤起 QuickBar，回车即答，可一键带入主窗口继续多轮
  • 节点小地图长对话左侧迷你导航，一眼总览、一键跳转任意一轮问答
  • 多家模型OpenRouter · OpenAI · Anthropic · DeepSeek · Gemini 自由切换
  • 思考与联网展示推理过程，支持联网搜索及图片 / PDF 附件解析
  • 数据自主全部对话本地存储，支持 Markdown 导出与一键备份恢复
