帮我写一个快速排序
好的，下面是 Python 实现：
def quicksort(a):
    if len(a) <= 1:
        return a
    p = a[len(a) // 2]
    return quicksort([x for x in a if x < p]) + [p] + quicksort([x for x in a if x > p])
