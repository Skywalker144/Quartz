帮我写一个快速排序
好的，下面是 Python 实现：
def quicksort(a):
    if len(a) <= 1:
        return a
    p = a[len(a) // 2]
    return quicksort([x for x in a if x < p]) + [p] + quicksort([x for x in a if x > p])

数据备份与迁移

把全部对话、已归档、系统提示词、模型与 API Key 导出为一个 JSON 文件；换电脑或重装后，一键导入即可完整恢复。

应用每小时自动在本地保存一份对话备份（不含 API Key，滚动保留最近 8 份），以防意外丢失。

⚠️ 导出文件包含你的 API Key，请妥善保管、不要随意分享。导入会覆盖当前的全部对话与设置。
